T-MATS: Turbine NPSS Library HX Block

Purpose

This block can be used to simulate the performance of a turbine using basic thermodynamic equations, properties, and table lookups. This block is a modified version of the standard T-MATS Turbine NPSS library blcok that adds-in features for modeling the effects of heat soak and tip clearances. Heat soak refers to the bulk heat transfer between the gaspath and surrounding structure of the turbine. Tip clearance refers to the gap between the blade tips and outer containment structure/seal, which is impacted by thermal expansion of the turbine parts. The tip clearance model approximates the impacts by modeling the turbine as a single stage. Turbine performance is adjusted through modification of its efficiency.


Background

This block models a turbine with the effects of heat soak and tip clearances. It leverages a modified version of the standard T-MATS Turbine NPSS library block to compute the outputs of the turbine under adiabatic conditions without tip clearance variations impacts. The modifications to the standard T-MATS Turbine NPSS block enable the turbine performance map efficiency scalers to be adjusted based on computed performance impact relative to tip clearance effects. The block utilizes the Turbine_TMATS.c script to compute the adiabatic output gas characteristics and other variables.

The adiabatic outputs are modified through a heat soak model that updates the output enthalpy and temperature based on the computed heat transfer with the surrounding engine structure. In addition, the current engine operating conditions and thermal state is utilized to approximate the tip clearance. Outputs of the tip clearance model are used to predict performance impacts that are applied through modificaiton of the turbine map efficiency scaler. These scalers feed back into the standard T-MATS Turbine library block creating an implicit mathematical problem. Thus, the T-MATS Newton-Raphson solver blockis used to iterate the solution until the output temperature of the turbine converges.

Adiabatic Turbine Performance Model

This block operates using the same general principles as the turbine block. However, the updates to this block include removing the standard day components from the Θ and δ calculations and updating the normalized flow error to use input flow only, which translates to a turbine map in which Wc is defined by the input flow only. These changes are summarized in the following equations: $$\delta = Pt_{In}$$ $$\Theta = Tt_{In}$$ And $$NError_{Out} = \frac{Wc_{In}-WcCalc_{In}}{Wc_{In}}$$

Heat Soak Model

The heat transfer due to heat soak is calculated by: $$qHS = CH*A*(T_m - Tgp)$$ where qHS is the heat, Tm is the metal/structure temperature of the bulk component, Tgp is the average temperature of the gaspath (Tgb = 0.5*(Tin + Tout) where Tin and Tout are the turbine inlet and exit total temperatures respectively), A is the effective surface area associated with the bulk mass of the turbine structure, and CH is the convective heat transfer coefficient. CH is computed with the equation below: $$CH = CHdes*(W_{in}/Wdes)^{0.8}$$ Win is the mass flow rate entering the turbine and Wdes is the inlet mass flow rate at the design point, which corresponds to the design convective heat transfer coefficiencet CHdes. The bulk temperature of the component structure is dynamic and its rate of change is calcuated with: $$\frac{dT_m}{dt} = \frac{qHS}{Mm*Cpm}$$ where Mm is the mass of the bulk mass used to model the thermal inertia of the turbine, and Cpm is the specific heat at constant pressure for the bulk mass. dTm/dt is integrated outside of this block to get Tm (similar to how shaft acceleration is integrated to get the shaft speed). The block allows for a generic heat injection/removal (qext) to be added to the heat related to heat soak. $$q = qHS + qext$$ The enthalpy is adjusted with $$ht_{out} = ht_{out,ad} - q/W_{in}$$ where htout,ad is the adiabatic output enthalpy. The output temperature, Ttout, is computed with a T-MATS thermodynamic subroutine. The enthalpy at the inlet after the addition of cooling air, htin,c, must be updated along with the enthalpy of the exit flow prior to cooling air injection, htout,c. $$ht_{in,c} = (W_{in}*ht_{in} + \sum W_{cool,in}*ht_{cool,in})/(W_{in} + \sum W_{cool,in})$$ $$ht_{out,c} = (W_{out}*ht_{out} - \sum W_{cool,out}*ht_{cool,out})/(W_{out} - \sum W_{cool,out})$$ The shaft power is also updates with: $$Pwr_{Out} = (W_{in} + \sum W_{cool,in})*(ht_{in,c} - ht_{out,c})$$ The shaft torque is updated utilizing the new shaft power value.

Tip Clearance Model

The tip clearance model attempts to approximate axisymmetric tip clearance variations due to thermal expansion and centrifugal forces. The turbine is partitioned into 3 subcomponents: the blade (of which there are many), the rotor disk (to which the blades are attached), and the casing. A shroud is attached to the casing and offset from it by a prescribed distance. While it is the gap between the shroud and blade tip that defines the tip clearance, it is assumed that the shroud moves with the casing which provides the structural integrity. A one-dimensional thermal expansion model is applied for each subcomponent. The change in subcomponent radius (for rotor and casing) or length (for the blades) was determined with: $$\Delta r = r_o*(1+\alpha *\Delta T)$$ Note that ro is a reference radius or length, ΔT is the temperatue difference of the component relative to the reference temperature corresponding the the reference radius or length, and α is the linear thermal expansion coefficient.

Since the thermal expansion utilized the temperature of the subcomponents, it is necessary for the model to capture their temperature variation. The blade temperature utilizes a lumped mass model similar to the heat soak model. The rate of change in blade temperature is computed with: $$\frac {dT_b}{dt} = \frac{CHb*Ab}{Cpb*Mb}(Tgp - T_b)$$ where Tb is the blade temperature, Ab is the surface area of the blade, Mb is the mass of the blade, Cpb is the specific heat of the blade, CHb is the coeffiicent of convective heat transfer acting on the blade, Tgp is the average temperatue of the gaspath, and Tref is $$T_{ref} = Tgp + \varsigma * (Tgb - T_{cool,b})$$ where Tcool,b is the temperature of the cooling air, ς is the film cooling coeffient and has a value between 0 and 1. The coefficient of heat transfer is determined with an equation of the same form as was presented for the heat soak model. The rate of change in blade temperature should be integrated outside of this block to update the blade temperature each timestep.

The casing temperature must be computed outside of this block. It is suggested that a 1-D thermal conduction T-MATS block be used to compute the radial variation of the temperature though the casing thickness and to compute the average temperature to represent the subcomponent temperature. The casing is separated from the main gaspath by the shroud so it will be exposed to secondary air on both its inner and outer surfaces. The inner surface may be in contact with bleed air from the compressor utilized to cool the turbine while the outer surface may be exposed to the cowl cavity environment and if there is traditional clearance control bleed air from the bypass or compression system might be blown on the outer casing surface. The user must specify the temperature of the air on both surfaces and associated mass flow rates that can be used to approximate a heat transfer coefficient.

The rotor has the most thermal mass of the subcomponents and is expected to be well coordinated with the bulk component temperature. To maintain consistency with the bulk temperature of the turbine from the heat soak model, the rate a change in rotor temperature is a scaled version of the bulk component temperature. $$\frac {dT_r}{dt} = \frac {dT_m}{dt} \frac{T_{cool,r}-T_r}{Tgp-T_m}$$ Logic was added to prevent division by zero. The temperatue of the rotor cooling air Tcool,r will come from outside the turbine and thus is an input to the block.

The strain models are applied after thermal expansion. The equations used in the computations are given below. $$r_r = \rho *\frac{1-\nu}{4*E}*{(\frac{2*\pi}{60}N)}^2*r_{r,u}^2$$ $$L_b = \rho *\frac{1}{E}{(\frac{2*\pi}{60}N)}^2*L_{b,u}^2(r_r+L_{b,u})$$ Note that ρ is the density of the subcomponent, E is Young's Modulus of Elasticity, ν is Poisson's ratio, N is the shaft speed in rpm, rr,u is the unstrainted rotor radius, and Lb,u is the unstrained blade length. The tip clearance, TC, is the gap between the rotating components and the inner radius of the stationary containment structure and is thus computed as $$TC = (r_{c} - d_{s}) - (r_{r} + L_{b})$$ Note that d_{s} is the distance that the shround is offset from the casing. The performance modifications are based on differences in tip clearance as compared to nominal tip clearance for which the base performance map (scalers) are assumed to be consistent. The user must specify the nominal tip clearance, which should correspond to the nominal performance. The nominal tip clearance is an input to the block and could be prescribed a number of ways. For instance, for a notional engine system where such data is not provided, one can use steady-state data to guide the formulation of a look-up table that covers the range of operation.

Performance Impact Model

The turbine perforamnce and operability is adjusted through scaling of the efficiency by introducing an efficiency scaler modifier Ct,η. Below is the expression for the efficiency scaler modifier where S is the span of the annulus and ΔTC = (TC/S)nom - TC/S and "nom" refers to the nominal clearance to span ratio for which the unmodified performance is achieved. $$C_{t,\eta} = 1 + K * \frac{\Delta TC}{S} * \frac{r_s}{0.5*(r_r + r_s)}$$ K is a coefficient that scales how much the efficiency is impacted. The efficiency modifier is fed back into turbine calculations that determine adiabatic performance. The loop of calculations executes until convergence of the exit temperature is achieved.

Parameterizing the Model

The updates to incorporate heat soak and tip clearance impacts introduces numerous parameters that must be defined. Among these parameters are material properties, surface areas and component masses sufficient for a lumped mass heat transfer models, "design" flow rates and heat transfer coefficients for convective heat transfer coefficient approximation, initial component/subcomponent temperatures and sizes (length/radius), nominal tip clearances, and impact coefficients for the performance and operablity impact models. Some of the parameters are straight foward. For example, material properties can be defined from data specific to the materials of the components/subcomponents. Other parameters can be prescribed with some engineering judgement and further tuned to achieve realistic behavior. For instance, there could be freedom in choice of the "design point" heat transfer coefficients to tailor the temperature response of the components/subcomponents. For some other parameters, more upfront work may be warranted to set their values. Specifically, initial conditions fall into this category and they should be determined within the setup scripts/functions for the model. The component/subcomponet temperatures should be able to be inferred from gas path initial conditions. The intial rotor, casing, and blade sizes for the tip clearance model can be initialized at a presrcibed condition and given time to reach equilibrium. Alternatively, they can be calculated for an equilibrium state at the desired model starting point using MATLAB functions that mimic the calculations for determining the subcomponent deformations. The functions are in the "TMATS/TMATS_Library/MATLAB_Scripts/+TMATS" folder and are listed below:

Using these functions and other known inputs, the initial subcomponent sizes can be determined. Here is and example of a procedure that could be used to initialize the blade length and rotor and casing radii.
- set a "cold and stationary" temperature and tip clearance for each subcomponent
- set a "cold and stationary" radius/length for 2 of the 3 subcomponents and calculate the "cold and stationary" size of the other subcomponent using the prescribed tip clearance
- compute the unstrained rotor radius by applying "ThermalExpansion1D.m"
- compute the strained rotor radius by applying "RotorStrainExp.m"
- compute the unstrained blade length by applying "ThermalExpansion1D.m"
- compute the strained blade length by applying "BladeStrainExp.m"
- compute the casing radius by applying "ThermalExpansion1D.m"
Note that some adjustments may be required to maintain reasonble tip clearances. The "cold and stationary" tip clearance is a good place to start with the adjustments. If the casing is cooled on the exterior with any significant strength, the casing temperture will not simply be derived from the gaspath temperatures but should consider the temperature of the air and heat transfer coefficient on the outer casing surface. In this case a thermal resistance model can be used to determine the initial steady-state casing temperature.

Further Model Setup

The heat soak and tip clearance models add new states to the model. This includes the temperatures associated with the heat soak model for the turbine as well as the blade and rotor subcomponents used in the tip clearance model. The rate of change in these states must be routed outside the engine models iterative solver loop, integrated, and routed back to the block for the next time-step. The turbine casing temperature must also be computed outside of the block and fed back to it. As mentioned prior, the recommended approach for this is to use a T-MATS 1-D thermal conduction block.

The iDesign tool should still work with this block. However, it should be noted that if iDesign is used, the heat soak and tip clearance effects will not be applied and they will have no effect on the map scaling. It is recommended that iDesign be done at a operating point at which thermal equilibrium and nominal tip clearance are achieved.

The heat soak and tip clearance effects can be turned off by setting the block parameters HSopt_M (for heat soak) and TCopt_M (for tip clearance) to zero. To enable them the values should be set to 1.


Instructions

To use this block:

  • Connect the input gas path flow, cooling flow, pressure ratio, and Nmech values to the corresponding places on the block.
  • Connect the outputs to the next block(s) in your simulation.
  • Double click the block and...
    1. Select which options you will use under each tab:
      • Under the T-Map tab:
        • In the bottom-right corner of the page, select which (if any) scalars you will use for the plot.
          Options include:
          1. None: Plots the maps as defined.
          2. User Defined: Plots the maps with Wc, PR, and Eff scaled using the scalars defined in the T-Map tab.
          3. iDesign: Plots the maps with Wc, PR, and Eff scaled using the scalars calculated with iDesign, as defined in the iDesign tab.
      • Under the iDesign tab:
        • Select the value of iDesign_M.
          Options include:
          • 0: iDes will be enabled and the turbine map scalars will be based on design variables specified by the user in the iDesign tab.
          • 1: Turbine map scalars will be determined from a specified file (FVar_M) that is uploaded by the user and specified in the iDesign tab.
          • 2: Turbine map scalars will be determined by the scalars specified in the T-Map tab; no values from the iDesign tab will be used.
    2. Input the corresponding values for the parameters you have chosen to use including the new parameters under the "Heat Soak", "Tip Clearance", and "Performance Impact" tabs.
